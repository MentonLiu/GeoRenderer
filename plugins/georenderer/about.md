# GeoRenderer

在“视图”或“工具”菜单中打开 GeoRenderer，按顶部四步导航完成模型渲染：

1. 镜头与材质：确定画幅、相机和组级材质。左侧使用常规 3D 预览，不启动路径追踪。
2. 场景：选择工作室、主世界、末地或下界氛围，调整时间、太阳和地面纹理。可用时读取 Blockbench 已加载的内置环境贴图。
3. 预览渲染：调整采样、光线反弹、降噪与后期效果，在缩小分辨率下实时路径追踪。
4. 最终导出：确认参数并开始最终渲染。完成后复制图片、另存 PNG，或打开 Blockbench 截图面板。

- 左键拖动旋转；右键或 Shift + 左键拖动平移；滚轮缩放。
- 支持程序化天空、HDR 和普通图片环境光。
- 支持按组及逐纹理覆盖材质、降噪、后期处理与透明背景 PNG。
- 需要 WebGL2 和 `EXT_color_buffer_float`。
