# GeoRenderer

在“视图”或“工具”菜单中打开 GeoRenderer，按顶部五步导航完成模型渲染：

1. 材质：独立窗口左侧显示模型，右侧组大纲只列出组。点击模型部件即可定位并选中所属组，编辑粗糙度、金属度与自发光。
2. 场景：同一窗口实时显示所选环境、时间、太阳和地面纹理。
3. 相机：确定画幅、位置、投影与景深。进入预览后镜头固定，返回本步可修改。
4. 预览渲染：调整采样、光线反弹、降噪与后期效果，在缩小分辨率下实时路径追踪。
5. 最终导出：确认参数并开始最终渲染。完成后复制图片、另存 PNG，或打开 Blockbench 截图面板。

- 左键拖动旋转；右键或 Shift + 左键拖动平移；滚轮缩放。
- 前两步使用检查视角，镜头设置只在第 3 步影响最终渲染。
- 支持程序化天空、HDR 和普通图片环境光。
- 支持按组及逐纹理覆盖材质、降噪、后期处理与透明背景 PNG。
- 需要 WebGL2 和 `EXT_color_buffer_float`。
